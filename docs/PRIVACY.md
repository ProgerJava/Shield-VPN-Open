ShieldVpn — это быстрый VPN-клиент, который предоставляет защищенные сетевые туннели с использованием протокола VLESS.

🔒 **Наша политика «No Logs» (Без логов)**: мы НЕ собираем и НЕ храним информацию о вашей активности в интернете:\
• Историю посещенных сайтов\
• DNS-запросы\
• IP-адреса во время сессии\
• Содержимое вашего трафика

📋 **Данные аккаунта**: для работы сервиса (авторизация) мы можем обрабатывать минимальный набор данных:\
• Номер телефона\
• Данные об устройстве (версия ОС, модель) — для технической поддержки

При авторизации через VK ID или Telegram мы получаем ваш номер телефона 
и немедленно передаём его на наш защищённый сервер по зашифрованному 
соединению (HTTPS).

На сервере номер телефона преобразуется в криптографический хеш (SHA-256). 
В нашей базе данных хранится только этот хеш — восстановить из него 
исходный номер телефона невозможно.

Хеш используется для:\
• Предотвращения использования более чем 1-ого устройства одновременно\
• Идентификации аккаунта при технической поддержке

Мы не храним и не обрабатываем ваш номер телефона в исходном виде после завершения авторизации.

Мы не продаем ваши личные данные третьим лицам. Данные могут передаваться только партнерам, необходимым для работы сервиса (например, платежным системам для обработки подписки).

Ваше использование приложения означает согласие с нашей Политикой конфиденциальности.
